Data-DrivenDublin

Graduate capstone Python · SQLite · R · ArcGIS · GitHub Actions

A four-person capstone for my M.S. at Ohio State. We built a pipeline that pulls American Community Survey data from the Census API into a SQLite database, then used k-means clustering to narrow almost 2,400 U.S. places to the 51 most like Dublin, Ohio.

Helicopters andPacific brant

Graduate project R · logistic regression · slide deck

A three-person statistics project for my M.S. at Ohio State. We used logistic regression to find how close a helicopter can fly before flocks of Pacific brant take flight at Izembek Lagoon, Alaska, and turned the model into flight guidance.
